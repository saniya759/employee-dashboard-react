# Employee Dashboard

React employee management dashboard — search, sort, pagination, and add/remove functionality (CDN-based, no build step)

## Features
- Sidebar navigation
- Stats cards (Total Employees, Departments, Active, Avg Salary)
- Search by name, department, or role
- Sortable columns (Name, Department, Salary)
- Pagination
- Add new employee via modal form
- Remove employee
- Fully responsive

## Tech Stack
React 18, Babel Standalone (loaded via CDN — no build step needed)
